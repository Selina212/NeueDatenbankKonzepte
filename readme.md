# Lagerverwaltung – MongoDB Projekt

Kleines Lagerverwaltungsprojekt mit REST-API und eigener HTML/JavaScript-GUI.

## Technologien

### Backend
- Node.js
- Express
- Mongoose
- MongoDB Atlas
- dotenv
- cors

### Frontend
- HTML
- CSS
- JavaScript
- Fetch API

## Projektstruktur

```txt
backend/
├── config/        # Datenbankverbindung
├── models/        # Mongoose-Models
├── routes/        # Express-API-Routen
└── server.js      # Einstiegspunkt Backend

frontend/
├── css/           # Stylesheets
├── js/            # Frontend-Logik und API-Funktionen
└── *.html         # GUI-Seiten
